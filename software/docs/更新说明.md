# 2026年11月18日公开源码更新

相对11月16日交付版本，汇总本次同步的最终功能。中间试验和已取消方案不作为当前功能；技术测试不代表真人识别准确率达标。

1. **改为一个统一动作模型。** 摄像头和录像共用特征与分类流程，不再为每个新动作并行加载一个识别模型。移除四份旧后台权重，保留第三方许可；公开包不提供作者新训练权重。
2. **支持从零联合训练。** 将当前资料足量的动作一起训练；不再强制先补齐谢谢、帮助、需要、我。未备齐任务继续保留，新模型只包含实际参与训练的类别。
3. **训练页简化为两个文件夹。** 每张卡片只有训练集、测试集，默认记录当前动作。录制后确认保存，轮次自动记录；旧validation资料兼容归训练视图。
4. **训练池内部自动划分检查资料。** 每类训练池至少20条作为起步条件，通常约20%留作内部检查；测试集不参加拟合或轮次选择。真实拍摄组保持完整，不把自动批次当独立真实组。
5. **支持旧背景和反例复用。** 后台复用本账号明确登记资料，也支持维护者明确批准的固定项目共享清单；校验来源、范围与修订并去重。测试、明确正例、排除资料不混入；账号媒体查看权限不变。公开包不包含原作者的共享清单或视频。
6. **逐动作检查训练是否达标。** 每类召回率≥90%、精确率≥90%、误报率≤5%，并满足目标/非目标测试各20条。未达标保留任务，不能只用平均分宣布成功，也不能对未变化资料反复随机刷分。
7. **支持64个动作任务及归档恢复。** 可建立已有动作的资料卡、移除或恢复任务；所有参与动作达标并发布成功后，自动移除卡片，原视频保留供后续联合训练。
8. **中文整理与段末语音播报。** 已确认词序按有限规则断句与整理，原词序可展开；不完整、歧义内容不自动读。实时页与摄像头端共用流程。
9. **自动结束一段。** 双手移出画面约2秒后自动整理；重新入镜可以续接，手动结束作为备用。语音播放时仍可识别下一段。
10. **数字人按输入播放动作。** 文字或核对后的语音转写驱动动作拼接；完善部分常见就医说法、缺词/超限提示和慢响应取消，编辑或清空同步停止旧播放。
11. **取消配对码、固定绑定和固定医院场景。** 同账号直接同步独立显示端，保留账号隔离与指令去重；旧场景地址跳转首页，动作素材保留。
12. **精简学习页。** 移除当前账号可识别提示、顶部操作说明和原四词标签行，保留动作预览、录制与保存。

公开包只交付源码、必要运行资源、空数据库结构及公开说明，不包含私人录像、数据库内容、凭据、新统一训练权重、原机共享清单或私人Git历史。使用者需用自己的视频训练或配置合法模型；没有模型时采集训练可用，动作识别不可用。

已有数字人动作不等于已训练识别动作。统一模型的真人现场效果仍需优化，本次未证明独立准确率提升或所有动作达到90%。专业核验、跨人/跨电脑摄像头与真实扬声器听感仍待验证，安卓研发暂缓。
