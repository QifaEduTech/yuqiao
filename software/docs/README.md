# 软件部署说明

本公开交付以 [software/README.md](../README.md) 为唯一安装与配置说明。

四岗独立演示代码见[四岗独立代码](四岗独立代码.md)与[四岗代码摘录](四岗代码摘录.md)；医院互助30词计划在[项目计划](../项目计划/)，`项目进度数据.json`只是公开摘要，完整台账不随源码发布。

Nginx 默认 HTTP 局域网 8080、可选 `-Https` 和 Cloudflare 公网说明见[Nginx反向代理](Nginx反向代理.md)与[公网部署](公网部署.md)。
