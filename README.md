# 语桥无界

语桥面向医院互助与公共服务窗口接待与求助，将文字／语音输入、已有数字人手语表达、摄像头有限词汇识别与播报连接到Web页面，并提供词典、学习、录像记录和自助动作训练入口。

**当前状态：待接收人复现验收。** 内置实时识别谢谢、帮助、需要、我；文字到手语只播放已有目录可表达的内容。不是任意连续手语翻译，也不替代专业翻译。安卓研发搁置，当前交付Web。

**负责人／备用负责人、软件维护人：** 待项目团队填写。**硬件负责人：** 当前Web不涉及自制硬件。

**飞书项目页：** 待团队补链接。项目总台账、PPT、逐字稿和比赛材料按组织模板在飞书维护，不放公开源码包。

**比赛版本／对应硬件版本：** 当前分支供审核，最终比赛版本待团队确认；无已交付板卡。

## 2026-11-16 更新

- 三个登录入口：正常端 /、纯数字人显示端 /avatar、摄像头识别端 /camera。账号通用；同账号正常端可向数字人端发送动作、暂停和重播，未连接时有提示。配对码、管理员固定绑定与指令编号去重尚未实现。
- 训练改为任务卡片和六个录像文件夹：学习/练习后检查/最后考试各分“这个词”和“不是这个词”，目标数量分别为每类3/3/20条。点入口后开始录制、结束、确认保存，类别和用途自动沿用入口，轮次由系统记录。
- 自动轮次是整理批次，不代表已确认的独立真人拍摄条件。保存不自动训练；资料够后手动开始训练，过程中自动检查质量。用户不再需要补录旧词检查，旧词回归不再作为发布/启用前置；当前词考试仍需正反各20条、召回/精确率至少90%、误报不高于5%。
- 取消训练资料4秒上限，保留至少0.5秒和现有30秒原片边界。新自训练模型按训练/验证片段长度记录识别窗口；已有模型保留原行为。录制保存失败可重试，已上传原片不重复上传。
- 实时页 /realtime.html 支持已接入词自由成段、段末播报；独立摄像头端 /camera 为稳定候选即播。真实自然连续、跨使用者和30词规模效果仍待验证。
- 医院互助30个数字人动作初稿与14句场景已提供，/hospital-scene.html 可逐句/整段播放。全部动作仍未专业验收；内置摄像头识别仍为谢谢、帮助、需要、我四词，动画数量不等于识别词数。

仍待完成：每账号20个训练任务上限的扩容、跨电脑HTTPS摄像头和真人播报实测、配对码/固定绑定。HTTPS使用端需信任本地CA；安卓继续暂缓。专业动作修正随制作进行，不把演示或模拟测试当作真人验收。

## Windows 从零启动

完整步骤、官方链接、模型下载和成功标志见 **[软件安装与运行说明](software/README.md)**。

1. 安装MySQL 8.0，使用自己的账号密码。只在新环境导入`software/database/schema.sql`，建立yuqiao及10张空表；已有同名库先核对，不能覆盖。
2. 双击 **Deploy-Web.cmd**。准备Node、Python、Ollama与依赖，提示填写本机数据库凭据，下载模型、构建并启动。软件源、UAC和数据库安装可能需要操作，不承诺完全无人值守。
3. 看到`Ready: http://127.0.0.1:8080/`后打开首页；同一局域网用`http://<电脑IP>:8080/`。注册自己的账号，在账号设置填写自己的百炼中国内地API Key并试听。默认HTTP；手机摄像头或HTTPS用`Start-Yuqiao.cmd -Https`，公网用`Start-Public.cmd`。
4. 日常 **Start-Yuqiao.cmd**，结束 **Stop-Yuqiao.cmd**。首次数据库连接也可单独运行 **Configure-Database.cmd**（需先装Node与npm依赖）。

公开包不含真实API Key、数据库密码、账号数据、私人录像、SQL数据备份或原机DPAPI密文。只提供空库结构与新机配置入口。
