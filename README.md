# 语桥无界

语桥面向医院互助与公共服务窗口接待与求助，将文字／语音输入、已有数字人手语表达、摄像头有限词汇识别与播报连接到Web页面，并提供词典、学习、录像记录和自助动作训练入口。

**当前状态：待接收人复现验收。** 公开源码不附作者训练权重，识别类别取决于使用者本机训练模型；文字到手语只播放已有目录可表达的内容。不是任意连续手语翻译，也不替代专业翻译。安卓研发搁置，当前交付Web。

**负责人／备用负责人、软件维护人：** 待项目团队填写。**硬件负责人：** 当前Web不涉及自制硬件。

**飞书项目页：** 待团队补链接。项目总台账、PPT、逐字稿和比赛材料按组织模板在飞书维护，不放公开源码包。

**比赛版本／对应硬件版本：** 当前分支供审核，最终比赛版本待团队确认；无已交付板卡。

## 2026-11-18 更新

- 识别改为一个统一时序模型，实时摄像头与录像使用同一178维输入和模型版本。公开包不含作者训练权重、视频和数据库；识别需自行准备合法模型或使用自己的资料联合训练。
- 训练页只保留训练集、测试集两个入口；内部检查由训练池自动划分，旧validation资料兼容显示。每类训练池20条起步，不保证准确率。
- 支持64个动作资料任务、建立已有动作卡片、手动移除/恢复。达标才更新模型并归档卡片，原视频保留。
- 每轮从随机参数共同训练已准备好的动作，不强制旧四词；测试逐类复算召回≥90%、精确率≥90%、误报≤5%及样本数量。
- 背景/反例可复用本账号明确登记资料，或本机维护者明确批准的固定共享背景清单；不自动跨账号读取新资料，测试来源和媒体访问权限仍隔离。公开包不带原机共享清单。
- 实时和摄像头端在确认成段后做有界中文整理并播报，保留原始词序；不确定片段不自动读。双手出画约2秒自动收尾，手动结束仅备用。
- 取消配对码/固定绑定，数字人按同账号直接同步；取消固定医院场景面板，首页直接输入文字播放动作。
- 改善常见就医说法、缺词反馈、慢响应取消；学习页移除三处多余提示。

当前是有限词汇试用系统，不宣称独立真人准确率已达90%。专业动作核验、真实自然连续/跨人效果和跨机HTTPS仍待验证；安卓暂缓。详见[公开更新说明](software/docs/更新说明.md)。

## Windows 从零启动

完整步骤、官方链接、模型下载和成功标志见 **[软件安装与运行说明](software/README.md)**。

1. 安装MySQL 8.0，使用自己的账号密码。只在新环境导入`software/database/schema.sql`，建立yuqiao及10张空表；已有同名库先核对，不能覆盖。
2. 双击 **Deploy-Web.cmd**。准备Node、Python、Ollama与依赖，提示填写本机数据库凭据，下载所需公开运行资源、构建并启动；私有统一动作权重需自行提供或训练。软件源、UAC和数据库安装可能需要操作，不承诺完全无人值守。
3. 看到`Ready: http://127.0.0.1:8080/`后打开首页；同一局域网用`http://<电脑IP>:8080/`。注册自己的账号，在账号设置填写自己的百炼中国内地API Key并试听。默认HTTP；手机摄像头或HTTPS用`Start-Yuqiao.cmd -Https`，公网用`Start-Public.cmd`。
4. 日常 **Start-Yuqiao.cmd**，结束 **Stop-Yuqiao.cmd**。首次数据库连接也可单独运行 **Configure-Database.cmd**（需先装Node与npm依赖）。

公开包不含真实API Key、数据库密码、账号数据、私人录像、SQL数据备份或原机DPAPI密文。只提供空库结构与新机配置入口。
